# ElevatorSimulator

A C# console application simulating elevator movement in a large building, built with Clean Architecture and SOLID principles.

## Tech Stack

- .NET 10 
- xUnit

## Solution Structure

| Project | Layer | Responsibility |


## Getting Started

### Prerequisites
- [.NET 10 SDK](https://dotnet.microsoft.com/download)

### Run

```bash
git clone https://github.com/Graduate-Program-26/dotnet-elevator-Kemisetso.git
cd dotnet-elevator-Kemisetso
dotnet run --project ElevatorSim.Console
```

### Test

```bash
dotnet test
```
